## Oct 24, 2026
- It's been a year, and I finally decided to look back at my project to see my C# code. However I noticed that I forgot to upload the source code to my Git
- I tried to find the file but realised it was gna be on my old computer which I had no access to (oops)

Now OBVIOUSLY I wasn't gna write the code for it all again so I had to find some way to extract the code. 
I researched some online decompilers (also searched a little bit about the legality and ethics but it was my code so I didnt really care, I was just wondering if the decomplier would truly extract everything in that case)

- I ended up downloading ILSpy 11.1 (open-source decompiler) 
- I learnt that ILSpy would extract the code to about 85% percent of the original capacity as it would just change the variable names around a little for it to be more generic
- Whilst exploring ILSpy, I ran into a bug that I ended up reporting
